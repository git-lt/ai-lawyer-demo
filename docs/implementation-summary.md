## 🎨 设计亮点

### 1. 色彩运用
- **渐变背景**：首页、案件详情、个人中心使用渐变增强视觉吸引力
- **状态色彩**：成功(绿)、警告(橙)、信息(蓝)、错误(红)
- **透明度**：使用半透明背景营造层次感

### 2. 排版设计
- **字体层级**：2xl > xl > lg > base > sm > xs > 2xs
- **行高**：leading-relaxed 提升可读性
- **间距**：统一使用4px倍数

### 3. 图标使用
- **Carbon Icons**：统一的图标风格
- **语义化**：图标与功能匹配
- **大小适中**：text-xl, text-2xl 等

### 4. 卡片设计
- **圆角**：16px 大圆角
- **阴影**：shadow-sm 柔和阴影
- **间距**：p-4 内边距
- **背景**：bg-bg-card 卡片背景
